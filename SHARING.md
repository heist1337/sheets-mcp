# Передача коллегам

Передать ссылку на репозиторий. Коллега клонирует его, устанавливает uv,
копирует `.env.example` в `.env` и указывает свои Google credentials.
На Windows: `Copy-Item .env.example .env`.

Service account: JSON хранится вне checkout, путь задаётся через
`GOOGLE_APPLICATION_CREDENTIALS`. Нужные таблицы должны быть доступны email этого
аккаунта. Веб-вход в Google не выдаёт права сервисному аккаунту автоматически.
Не отправлять ключ вместе с репозиторием. Создание новых таблиц зависит от прав
и storage quota аккаунта; для пользовательского доступа доступен OAuth Desktop
из README.

В `mcp.example.json` заменить пути к checkout и приватному env-файлу. Клиент
запускает stdio-сервер сам. Для проверки без Google-ключа:

```bash
uv sync --locked
uv run python -m unittest discover -b -s tests
```

Живую проверку делать чтением метаданных `sheets_get` или явного диапазона
`sheets_read` существующей доступной таблицы. 403 означает необходимость проверить
права аккаунта, а не разрешение автоматически расширить доступ.

При переносе своей установки переносить credentials отдельно по защищённому
каналу и обновить пути. `.env`, service-account JSON и OAuth-токены не входят в Git.
